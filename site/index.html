Notes

Notes in the style of macOS, for Windows, Mac, Linux and Android, synced through your account.

Every platform

Windows 10 and 11

Installer (.exe)
  1. Open the downloaded file.
  2. If Windows says it protected your PC, choose More info → Run anyway. The app is not code-signed yet.

Mac

Disk image (.dmg), Intel and Apple silicon
  1. Open the .dmg and drag Notes into Applications.
  2. On first launch, if macOS refuses to open it, go to System Settings → Privacy & Security and click Open Anyway. The app is not notarised yet.

Linux (x64)

Ubuntu, Debian, Mint (.deb) Any distribution (.AppImage)
  1. .deb: sudo apt install ./win-notes_*_amd64.deb, then open Notes from your apps.
  2. .AppImage: chmod +x Notes-*.AppImage, then run it. Sign-in links from emails open the app only from the .deb.

Android 7 and later

App (.apk)
  1. Open the downloaded file on the phone.
  2. Allow your browser or file manager to install unknown apps when Android asks.

iPhone and iPad

Not available yet. Apple only allows installing apps through the App Store or TestFlight, which need an Apple developer account that Notes does not have yet.

Had the Android app before version 0.3.0? The new app has a new name and installs next to the old one, so nothing is lost:
  1. In the old app, sign in (or create an account) and stay online for a minute so every note syncs.
  2. Install the new app and sign in. Your notes appear.
  3. Then uninstall the old app.

Check a download

Each release lists every file's SHA-256 in SHA256SUMS. Compare it with sha256sum <file> on Linux, shasum -a 256 <file> on Mac, or Get-FileHash <file> on Windows. With the GitHub CLI, gh attestation verify <file> --repo zain-curricular/win-notes proves the file was built by this project's release workflow.

Source code and release notes: github.com/zain-curricular/win-notes.
