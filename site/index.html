Notes

Notes in the style of macOS, for Windows, Mac and Android, synced through your account.

Download
Latest release on GitHub

Windows

Installer (.exe)
  1. Open the downloaded file.
  2. If Windows says it protected your PC, choose More info → Run anyway. The app is not code-signed yet.

Mac

Disk image (.dmg)
  1. Open the .dmg and drag Notes into Applications.
  2. On first launch, if macOS refuses to open it, go to System Settings → Privacy & Security and click Open Anyway. The app is not notarised yet.

Android

App (.apk)
  1. Open the downloaded file on the phone.
  2. Allow your browser or file manager to install unknown apps when Android asks.
